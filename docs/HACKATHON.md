# Fishathon starter guidance considered

Reviewed 2026-10-07 against [`cartorgaOrg/fish-hackathon`](https://github.com/cartorgaOrg/fish-hackathon), commit [`4982c844662e910d857787427ce4dbd870670c0a`](https://github.com/cartorgaOrg/fish-hackathon/tree/4982c844662e910d857787427ce4dbd870670c0a).

The supplied repository is a starter kit with implementation and licensing guidance. The reviewed root README, root AGENTS, game-kit README/AGENTS and LICENSING files did not specify a separate judging rubric, submission deadline, team-size limit or competition eligibility rules. This document records the constraints present there; it does not claim to be a complete organizer rulebook.

## Applied to this deliverable

- **Voice is the focus.** The starter asks for game characters that speak, listen and converse using Fish Audio. This deliverable is the game-loop teammate’s portion. It provides the state/action contract; a complete hackathon demo still needs the voice teammate’s live integration. [Source: root README](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/README.md)
- **A custom engine is allowed.** The root README says the voice examples can work with the game kit, Unity, Godot or custom code. The plain-JavaScript/no-React rule in `game-kit/AGENTS.md` applies inside `game-kit/`. This standalone app lives outside that folder and retains the requested React/TypeScript/Vite/R3F stack. We did not alter or copy the starter’s engine. [Source: root AGENTS](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/AGENTS.md), [game-kit AGENTS](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/game-kit/AGENTS.md)
- **Credentials remain server-side.** No `FISH_API_KEY` or other service secret may enter browser code, including `VITE_*` variables. The voice teammate owns a separate service; this browser communicates through its chosen API/WebSocket boundary. No secret or placeholder credential is included here. [Source: root AGENTS](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/AGENTS.md)
- **Use documented Fish APIs.** Before the teammate writes voice code, follow the repository’s instruction to read/install the official Fish Audio skills and its voice-side guide. We did not install them because this scope contains no voice-service implementation. Examples 05 (game-aware replies) and 06 (custom STT → LLM → TTS) are relevant references; choosing/adapting a provider pipeline stays with the voice owner. [Source: voice guide](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/fish-audio/AGENTS.md)
- **Assets need provenance.** No outside creative assets were imported. Future imports must have a known license and a neighboring record of filename, author, license and source; required credits must be displayed. Starter CC0 packs are optional, not a requirement. If starter engine code is copied later, preserve its MIT license. [Source: licensing guide](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/LICENSING.md)

## Voice-owner handoff items

The starter licensing guide requires permission for cloned voices and describes plan-dependent commercial use. Have the voice owner review current Fish terms and obtain consent before adding a voice clone. The same guide says the `fish-audio/` example source has no stated license yet and directs teams to ask organizers before reuse; we have not copied that source. These are recorded starter instructions, not a legal determination. [Source: licensing guide](https://github.com/cartorgaOrg/fish-hackathon/blob/4982c844662e910d857787427ce4dbd870670c0a/LICENSING.md)

Before the team presents the final demo: connect actual voice input/output, confirm interruption handling across audio and actions, play a full repair by voice, and replace or hide the development adapter-status text. Keep the action console and solution presets absent from the player build. The game portion should remain runnable without provider credentials for independent development.
